# Yemot Hooks — תוסף VS Code

כש-Claude Code מבקש הרשאה, שואל שאלה או מסיים, הטלפון מצלצל דרך ימות המשיח.
בשיחת מענה אפשר גם **לענות מהטלפון**: לאשר או לבטל הרשאה, או לבחור תשובה לשאלה של Claude. השאלה מוצגת **גם במחשב באותו זמן**, והראשון שעונה קובע.
ויש גם **[צ'אט עם Claude בטלפון](#צאט-עם-claude-בטלפון)**: מתקשרים, מקליטים או מקלידים, ו-Claude עונה בקול.

כל ההגדרות יושבות בהגדרות של VS Code (`yemotHooks.*`), בדומה ל-Claude Notifier.
התוסף רושם ב-`~/.claude/settings.json` סקריפט node אחד (`~/.claude/yemot-hooks/hook.js`),
והסקריפט קורא את ההגדרות בכל הפעלה מ-`~/.claude/yemot-hooks/config.json`. לכן **שינוי הגדרה חל מיד**,
בלי לערוך את `settings.json` — הוא נכתב מחדש רק כשמדליקים/מכבים אירוע.

עובד גם ב-Remote-SSH: התוסף רץ בצד המכונה שבה רץ Claude Code (`extensionKind: workspace`).
דרישה יחידה: `node` ב-PATH של המכונה (אין יותר צורך ב-PowerShell).

## פעולה לכל אירוע

| אירוע | אפשרויות |
|---|---|
| בקשת הרשאה (`needsPermission`) | כבוי · צינתוק · מענה בטלפון (1 = אישור, 2 = ביטול) |
| שאלה (`asksQuestion`) | כבוי · צינתוק · מענה בטלפון (השאלה והאפשרויות מוקראות, הבחירה חוזרת ל-Claude) |
| סיום משימה (`taskCompleted`) | כבוי · צינתוק |
| סוכן-משנה סיים (`subagentCompleted`) | כבוי · צינתוק |

לכל אירוע אפשר יעד משלו (`<event>.target`): `list:1,2` · `phones:0501234567` · `template:123`,
וגם **זיהוי יוצא משלו** (`<event>.callerId`). למשל, הרשאה מצלצלת מזיהוי אחד וסיום משימה מזיהוי אחר, כדי לדעת מי מצלצל לפני שעונים.

### הגדרה מתוך נתוני ימות

אין צורך להקליד מספרים ושמות. הפקודות טוענות אותם מהמערכת:

| פקודה | מה נטען |
|---|---|
| **הגדר אירוע** | פעולה, ואז יעד (רשימות צינתוק עם מספר הנרשמים · תבניות · טלפונים), ואז זיהוי יוצא מהזיהויים המאושרים |
| **יעד ברירת מחדל** | רשימות צינתוק / תבניות / טלפונים |
| **זיהוי יוצא** | `GetApprovedCallerIDs`: המספר הראשי, המשניים, `RAND`, או מספר אחר |
| **שלוחת API** | עיון בעץ השלוחות (שלוחות API מסומנות), או יצירת שלוחה חדשה עם `api_link` נכון |
להרשאה יש גם סינון כלים (`needsPermission.tools`, regex — למשל `Bash|Write|Edit`).

## הגדרות כלליות

| הגדרה | |
|---|---|
| `enabled` | הדלקה/כיבוי של הכל |
| `target.method` / `target.lists` / `target.phones` / `target.templateId` | יעד ברירת המחדל (רשימת צינתוק = חינם) |
| `callerId` | זיהוי יוצא כברירת מחדל (ריק = ראשי, `RAND`); כל אירוע יכול לדרוס |
| `tzintukTimeout` | משך צלצול הצינתוק (1–16 שניות) |
| `quietHours` | שעות שקט, `22:00-07:00` |
| `ringDelaySeconds` | לצלצל רק אם לא ענית ב-VS Code תוך N שניות |
| `answerDelaySeconds` | מענה בטלפון: להתקשר רק אם לא ענית במחשב תוך N שניות |
| `minTaskDurationSeconds` | צינתוק סיום רק למשימות ארוכות מ-N שניות |
| `suppressSubagentInteractions` | בלי צלצול על הרשאות/שאלות מתוך סוכן-משנה |

## מענה בטלפון

| הגדרה | |
|---|---|
| `answerVia` | `call` — ימות מתקשרת ומכניסה לשלוחה · `tzintuk` — צינתוק, ואתה מחזיר צלצול לשלוחה |
| `serverUrl` | שרת הגישור (`main.py` / yemot-suite). **בלי** `/ask-hook` בסוף — ואם יוזן, יוסר |
| `ivrPath` | שלוחת ה-API בימות (למשל `5/5`). ה-`api_link` שלה = `<serverUrl>/respond` |
| `waitTimeout` / `callTimeout` | זמן המתנה לתשובה / משך חיוג |
| `inputType` | הקלדה לתשובה חופשית ("אחר") |
| `fallbackToTzintuk` | שיחה נכשלה (שרת לא זמין) → צינתוק במקום |

**גם המחשב עונה.** השאלה (AskUserQuestion) והבקשה להרשאה נשאלות ב-hook של `PermissionRequest`. Claude Code מריץ אותו בזמן שהוא מציג את החלון ב-VS Code או בטרמינל, ולכן אפשר לענות בטלפון או במחשב, והראשון קובע. תשובה בטלפון סוגרת את החלון במחשב. תשובה במחשב מפסיקה את ההמתנה לשיחה (דרך ה-`PostToolUse` של אותו כלי). לשאלה חוזרת תשובה אמיתית (`updatedInput.answers`), לא "דחייה עם הסבר". hooks שנרשמו בגרסה קודמת (`PreToolUse`) ממשיכים לעבוד עד שהתוסף רושם אותם מחדש.

## צ'אט עם Claude בטלפון

מתקשרים לשלוחת הצ'אט, מקליטים או מקלידים הודעה, ו-Claude עונה בקול. Claude רץ במחשב (`claude -p`) באחת התיקיות שהגדרת, וההודעה הבאה ממשיכה את אותה שיחה.

| מקש | מה קורה |
|---|---|
| 1 | הקלטה. ההקלטה מתומללת בשירות ההכתבה של Claude (אותו שירות שכפתור המיקרופון ב-Claude Code משתמש בו, עם ההתחברות של Claude Code במחשב) ומוקראת לאישור: 1 שלח · 2 הקלט מחדש · 3 בטל |
| 2 | הקלדה במקלדת העברית של הטלפון |
| 3 | שמיעת התשובה האחרונה |
| 4 | שיחה חדשה: בחירת תיקייה (עד 9), או "כללי" |
| 9 | סיום |

- **בזמן ש-Claude עובד** שומעים מוזיקת המתנה. התשובה מוקראת בלי קוד, טבלאות וקישורים, עד `chat.maxSpeak` תווים, ואחריה התפריט.
- **שאלות, הרשאות ותוכניות** של Claude נשאלות באותה שיחה: מקש לכל אפשרות, 8 לתשובה בהקלטה, 9 להקלדה. תוכנית: 1 אשר · 2 אשר ועריכות בלי לשאול · 3 דחה · 4 שינוי בהקלטה.
- **ניתקת לפני התשובה?** מגיע צינתוק, והתשובה מוקראת בתחילת השיחה הבאה.
- **🔒** רק הטלפונים שב-`chat.phones`. זיהוי מתקשר אפשר לזייף, ולכן כדאי להגדיר `chat.pin` (מקישים אותו בתחילת כל שיחה). Claude רץ בהרשאות המשתמש שלך, במצב `chat.permissionMode`.

**הגדרה:** הפקודה **הגדר צ'אט טלפוני**. היא שואלת על שלוחה (נפרדת משלוחת המענה), טלפונים ותיקיות, ומגדירה את השלוחה בימות: `type=api`, `api_link=<serverUrl>/chat/respond`, מוזיקת המתנה, דיווח על ניתוק ותיקיית `rec` להקלטות. שרת הגישור צריך את הגרסה עם `/chat/*` (`main.py` במאגר הזה).

**איך זה עובד:** התוסף מפעיל תהליך נפרד, `~/.claude/yemot-hooks/chat.js`, שממשיך לרוץ גם כשחלון VS Code נסגר. יש ממנו עותק אחד בכל רגע, והוא נעצר לבד כשמכבים את `chat.enabled`. התהליך מושך משרת הגישור את מה שהמתקשר עשה (`/chat/poll`) ושולח מה להשמיע (`/chat/screen`). השרת רק מנהל את השיחה, ו-Claude, התמלול וההיסטוריה נשארים במחשב. ההקלטה מורדת מתיקיית `rec` של השלוחה בלבד, ונמחקת משם מיד. דורש Node 22 ומעלה (לתמלול). אפשר להריץ אותו גם בלי VS Code: `node ~/.claude/yemot-hooks/chat.js`.

| הגדרה | |
|---|---|
| `chat.enabled` · `chat.ivrPath` · `chat.phones` · `chat.pin` | הפעלה, שלוחה, מי מתקשר, קוד גישה |
| `chat.projects` · `chat.defaultProject` · `chat.general` | התיקיות, הראשונה, ו"כללי" (שיחה בלי פרויקט) |
| `chat.permissionMode` · `chat.model` · `chat.maxMinutes` | איך Claude רץ |
| `chat.confirm` · `chat.hint` · `chat.maxSpeak` · `chat.missedTzintuk` | הקראת התמלול לאישור · בקשה לתשובה קצרה · אורך ההקראה · צינתוק אחרי ניתוק |

## פקודות (שורת הסטטוס → תפריט)

- **בדיקת תקינות** — node, טוקן ימות + יחידות, רשימות הצינתוק, שרת הגישור, וה-`api_link` של השלוחה.
- **שלח צינתוק בדיקה** / **שיחת בדיקה** — בדיקה מקצה לקצה.
- **הגדר את שלוחת ה-API בימות** — קובע `type=api` + `api_link=<serverUrl>/respond` (עם אישור).
- **הגדר צ'אט טלפוני** — שלוחה, טלפונים ותיקיות, והגדרת השלוחה בימות. בדיקת התקינות בודקת גם אותו.
- **הגדר טוקן ימות** — `env.YEMOT_TOKEN` ב-`settings.json` (הרשאה 600).
- **הצג יומן** — כל צלצול, תשובה ושגיאה נרשמים ב-`~/.claude/yemot-hooks/hook.log`
  (בגרסה הקודמת שגיאות נבלעו בשקט).
- **המר hooks ישנים** — hooks של PowerShell מדף ההגדרה הישן מומרים להגדרות ומוסרים.

## התקנה

```bash
cd vscode-extension
npx @vscode/vsce package --allow-missing-repository --skip-license -o yemot-hooks.vsix
code --install-extension yemot-hooks.vsix
```

או מה-Releases ב-GitHub. ב-Remote-SSH — מתוך החלון המחובר.

## הערות

- שינוי **רשימת** ה-hooks (הדלקה/כיבוי אירוע) חל על שיחות Claude חדשות; שינוי פרטים (יעד, שעות שקט…) חל מיד.
- "מענה בטלפון" על שאלה כבר לא חוסם את המסך: השאלה מוצגת במחשב בזמן שהטלפון מצלצל.
- בדיקות: `node test.js` (‏HOME זמני + שרתי מוק — שום בקשה לא יוצאת).
